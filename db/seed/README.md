# Seed-данные

Файлы в этой папке получены из реального дампа продакшн-БД (`shelter-route-planner`,
MongoDB, коллекции `shelters`, `comments`, `shelter_reports`, `shelter_submissions`)
и конвертированы в плоский JSON для загрузки в PostgreSQL/PostGIS через `db/import_seed.py`.

| Файл | Источник (прод-коллекция) | Записей |
|---|---|---|
| `miklats_seed.json` | `shelters` | 12 640 |
| `comments_seed.json` | `comments` | 15 |
| `reports_seed.json` | `shelter_reports` | 18 |
| `submissions_seed.json` | `shelter_submissions` | 72 |

## Приватность

Поля `reporter_ip` (в жалобах) и `submitted_by_ip` (в заявках на новое укрытие)
из оригинального дампа **намеренно не перенесены** — это IP-адреса реальных
пользователей прод-приложения, посторонние персональные данные, которым не
место в учебном репозитории. В новой схеме соответствующие колонки существуют
(`miklat_reports.reporter_ip`, `miklat_submissions.submitted_by_ip`), но остаются
`NULL` для всех сид-записей и будут заполняться только для новых обращений,
пришедших уже через это приложение.

`legacy_mongo_id` в каждой записи — исходный MongoDB `ObjectId`, нужен только для
связывания импортированных таблиц по внешним ключам (`import_seed.py` строит
по нему временную карту `mongo_id → postgres id`) и для трассировки происхождения
данных. На бизнес-логику приложения не влияет.

## Известная особенность данных (не баг импорта)

В исходном дампе часть `shelter_reports` (11 из 18) и часть `shelter_submissions`
(12 из 64 одобренных) ссылаются на `shelter_id`, которого нет в текущем срезе
коллекции `shelters` — судя по всему, эти укрытия были позже удалены из прод-базы
(например, после жалобы "closed"), а связанные записи остались. `import_seed.py`
такие "осиротевшие" ссылки пропускает и печатает точное количество пропущенных —
это ожидаемое поведение при работе с реальным историческим дампом, не повод
считать импорт сломанным.

Проверено (тестовый прогон): 12640 miklats, 15 comments, 7 из 18 reports
(11 пропущено), 72 submissions (из них 52 связаны с существующим miklat_id).
